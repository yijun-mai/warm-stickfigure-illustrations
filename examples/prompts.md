# 使用示例

## 只做配图规划

```text
使用 $warm-stickfigure-illustrations，先不要生图。
阅读下面文章，挑选真正值得配图的位置。给出配图位置、核心意思、火柴人动作和情绪、构图、短标注建议。不按每节平均分配。
【粘贴文章】
```

## 直接生成一组正文图

```text
使用 $warm-stickfigure-illustrations，为这篇文章生成3张独立配图。
16:9横版，奶油与浅蓝背景家族，人物都是线条火柴人，动作和表情鲜明。中文标注少而清楚。保存最终图片并告诉我放在哪段之后。
【粘贴文章】
```

## 单张情绪场景

```text
使用 $warm-stickfigure-illustrations，画“先听孩子把话说完”。
大人蹲下与孩子平视，孩子一开始有些委屈，大人认真听。温暖奶油底，珊瑚红和青绿少量点缀，手绘对话气泡。
图中文字只有“先听我说”和“我在听”。
```

## 知识关系/行动路径

```text
使用 $warm-stickfigure-illustrations，画“把大目标拆成眼前能做的一小步”。
一个火柴人从起点迈出第一步，远处目标不需要很大，路径只有少数节点。浅绿背景，暖黄和蓝色强调。文字只有“先走一步”。
```

## 局部改图

```text
使用 $warm-stickfigure-illustrations 编辑这张图，只把左边人物的表情从开心改为困惑，并把背景换成浅蓝；保留动作、构图、文字和其余人物，不新增装饰。
【附图】
```

## 比例与文字

```text
使用 $warm-stickfigure-illustrations，生成一张3:4竖版、没有文字的手绘图，表达同事把任务交给下一位时确认对方接住了。保持线条人物与轻松明亮的画风。
```

图中文字少时通常更容易检查，但生成仍可能错字。需要准确的长文字时，把解释留在正文，或单独使用有字体资源的排版流程。
