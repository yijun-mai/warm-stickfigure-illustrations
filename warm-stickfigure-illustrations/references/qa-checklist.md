# 验收与有限迭代

## 每张必查

- 内容：与当前文章/概念一致，没有添加未给的数据、引语或证据性信息。
- 人物：线条火柴人而非实心小怪物；动作参与主要表达。
- 情绪：眉眼、嘴与姿态一致，能读出要表达的状态；不默认人人微笑。
- 线条：自然微抖、有轻微粗细差，清楚而不脏乱。
- 颜色：背景柔和明亮，主体和文字对比足，强调色协调；不是必须某一套颜色。
- 构图：一个主意思，阅读顺序明确，复杂度不过载；允许自然错落。
- 文字：对照锁定文案逐字查看，无错字、伪字、漏字和多余字，缩小后仍可读。
- 负面风格：无照片、3D、商业矢量、冷峻HUD、复杂渐变和堆装饰。
- 比例：服从用户要求，不能因为默认16:9改掉竖图请求。
- 系列：角色语言一致，场景不同，不把所有例图复制一遍。

## 出问题怎么改

| 问题 | 优先修法 |
|---|---|
| 太商业矢量 | 明确不完美线宽和手绘轮廓，减掉完整卡通体块 |
| 人物没情绪 | 指定眉、嘴和身体动作；只改表情时保留其他内容 |
| 太杂 | 减次要装饰或物件，不靠缩小字挤内容 |
| 像PPT | 用一个有动作的场景替代机械节点排列 |
| 错字 | 短文案局部编辑；多处错则减字重生，不声称已准确 |
| 系列漂移 | 使用验收图作为角色/线条参考，不锁死所有背景色 |

通常最多额外修复2轮；用户要求更多时再继续。若缺工具、不能编辑或结果仍不理想，保留现有结果并明确未通过项。不用脚本画出来的图替代未生成的成品。
