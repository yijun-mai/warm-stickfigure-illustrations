# 构图与表达方式

选择最容易让读者看懂的结构，不强迫所有观点都变成机器或流程。

| 类型 | 适合内容 | 构图建议 |
|---|---|---|
| 生活场景 | 家庭相处、工作沟通、日常习惯 | 一个主要动作和少量环境线；人物相互朝向 |
| 情绪状态 | 困惑到理解、疲惫到轻松 | 用姿态表达变化，气泡点到为止 |
| 简单对比 | 两种做法或前后变化 | 左右/上下自然分区，不用机械表格；两边的比较维度一致 |
| 传递与协作 | 交接、反馈、共同完成 | 人物实际传递物件或回应，箭头标关系不抢戏 |
| 路线与小步 | 学习、尝试、行动路径 | 弯曲路径加少量节点，不把每句话变节点 |
| 知识手账 | 一个要点和两三处关联 | 主场景配手绘笔记、圈画与荧光标记；别做整页课程海报 |
| 概念隐喻 | 抽象关系难直接画出 | 找一个解释关系的动作/物件；成立即可，不必怪诞 |
| 小漫画 | 对话、行为后果、短过程 | 2–4格可作为同一张叙事图，每格推进同一个故事 |

## 从内容到画面

1. 用一句话写“读者看完要明白什么”。
2. 决定能直接画的动作或关系。能画放下手机、蹲下倾听，就不绕成复杂机器。
3. 选人物姿态与情绪，再安排一个必要物件和少量符号。
4. 决定是否需要文字。动作能表达就少写，必须精确的短文案先锁定。

画面轻松但有阅读顺序。手账感允许不对称和局部错落，不意味着文字重叠或视线来回找。主体周围留安静空间，留白由构图决定，不机械计算百分比。

## 避免套路

不要每张都画左右对比、都塞三个气泡、都加一排箭头。示例只提供线条、情绪与用色参考。同一主题换材料后应重新设计动作，不复制上一张图的对象和摆放。若用户明确指定某张作为参考，说明参考的是风格、角色还是构图，编辑时按其要求保留。
